# naverblog-persona

네이버 블로그 글을 만드는 기준을 한 곳에 모아 둔 저장소다. 블로그 글쓰기 지침은 여기에만 둔다. 다른 곳(Notion, 예약 작업 프롬프트, 별도 사이트)에 복사본을 만들지 않는다. 예전에 지침이 여러 곳에 흩어져 서로 덮어쓰다가 엉켰기 때문이다.

## 한 줄 요약

기사를 읽고 나서도 남는 질문 하나에, 직접 찾은 자료와 계산으로 답하는 글을 쓴다.

## 정해 둔 것 (2026-11-26)

| 항목 | 결정 |
|---|---|
| 목적 | 애드포스트 광고 수익 (승인 완료) |
| 주 유입 | 네이버 홈피드. 글마다 검색어 하나는 심는다 |
| 글의 성격 | 기사가 답하지 않은 질문 하나를 자료·계산·도표로 답한다 |
| 글쓴이 | 글에 나오지 않는다. 직업 경험·개인 의견·지어낸 경험 없음 |
| 독자 | 그 제목과 썸네일이 궁금해서 누른 사람 |
| 말투 | 해요체와 습니다체를 섞어 씀 |
| 분량 | 2,000~2,500자, 썸네일 1장 + 본문 이미지 2~4장 |
| 본문 이미지 | 기본은 단락 사이의 구분 그림(펜 스케치에 수채를 얹은 삽화, AI 생성 프롬프트로 전달). 도표·계산 카드는 글만으로 안 들어올 때만 |
| 발행 | 주 4편 |
| 다루지 않는 것 | 연예, 스포츠, 사건·사고 피해, 정치 공방, 종목 매수·매도 권유 |
| 운영자가 하는 일 | 소재 고르기, 제목 고르기, 붙여넣어 발행하기 (한 편 15분쯤) |

## 들어 있는 것

```
.claude/skills/naver-blog/
  SKILL.md                 핵심 한 장: 블로그 사정, 페르소나, 작업 흐름
  references/topic.md      소재 판정
  references/writing.md    본문 쓰기와 AI 티 점검
  references/visuals.md    제목, 썸네일, 본문 이미지를 무엇으로 어디에 넣을지
  references/scene-images.md  구분 그림의 이미지 생성 프롬프트와 고정 스타일
  references/naver.md      네이버 홈피드에 대해 확인된 것과 모르는 것
  assets/thumb.html        썸네일 틀 (1080×1080)
  assets/card.html         본문 카드 틀 (계산·막대·순서·표·선 그래프)
  assets/fonts/            Pretendard 글꼴 (OFL)
  scripts/render.cjs       HTML → PNG
  scripts/linechart.py     선 그래프 SVG 만들기
log/posts.md               발행 기록
```

## 쓰는 법

이 저장소가 붙어 있는 Claude Code 세션에서는 스킬이 자동으로 잡힌다. 이렇게 말하면 된다.

- 기사 링크나 소재를 주면서 "이걸로 블로그 글 써 줘"
- "블로그 소재 뽑아 줘"
- 발행한 뒤 "방금 글 주소는 … , 조회수 … , 홈피드 비율 …"

다른 곳(claude.ai 등)에서 쓰려면 `.claude/skills/naver-blog` 폴더를 스킬로 올린다.

## 알아 둘 것

- 글이 기사와 달라지려면 공공기관 원자료를 직접 열어 봐야 한다. Claude Code 클라우드 세션의 기본 환경은 한국은행·은행연합회 같은 사이트 접속이 막혀 있어서, 그 상태에서는 검색 결과로만 숫자를 맞추게 된다. 이때는 전달 메모의 "올리기 전 확인"에 직접 열어 볼 주소가 적혀 나온다. 환경의 네트워크 설정에서 해당 사이트를 허용하면 원문 확인까지 한 번에 된다.
- 2026-11-26에 이 스킬만 주고 글 한 편을 끝까지 만들어 보는 시험을 한 번 했다. 거기서 막힌 곳을 고친 것이 지금 판이다.

## 고칠 때

- 규칙을 더하기 전에 기존 줄을 고치거나 지울 수 있는지 먼저 본다. 지침이 길어질수록 글이 지침을 지키느라 딱딱해진다.
- 글 한 편에서만 생긴 문제는 규칙으로 올리지 않는다. 여러 편에서 반복될 때만 올린다.
- 네이버에 대한 내용은 근거 수준(네이버가 밝힌 것 / 경험칙 / 모르는 것)을 구분해 `references/naver.md`에 적는다.

## 아직 정하지 않은 것

- 블로그 이름. 틀에는 임시로 「기사 다음 장」이 들어가 있다. 바꾸려면 `assets/thumb.html`과 `assets/card.html`의 이름 한 줄씩을 고친다.
- 네이버의 "AI 활용" 표시를 켤지. 선택 사항이고 운영자가 정한다.
